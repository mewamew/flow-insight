# 数据目录

`runtime/` 保存本人的设置、SQLite 和真实采样，`test-runtime/`、`validation/` 保存隔离测试产物。这三个路径均被 Git 忽略，不得提交密钥或真实画面。

共享的合成测试图片在 `tests/fixtures/`，产品示例会话在 `src/demo/session.json`，它们可以跟踪。导出的个人记录自行保管，不自动公开。

新版只保存按需采集的屏幕 JPEG；摄像头帧在原生进程内存中完成在座检测，Rust 仅收到检测状态、置信度和时间。数据库中的本地观察记录不含图片。旧版摄像头图片保留至用户主动删除或按既有保留周期到期，不再上传。
